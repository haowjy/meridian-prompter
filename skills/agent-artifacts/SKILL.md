# Agent Artifacts

Meridian ships its own guide to agent profiles: where they live, what callers see, what
Meridian adds to the prompt, what reaches a spawn, models, and permissions. Read it with
`meridian skills prompt-authoring__meridian`, then its `resources/agents.md` (and
`resources/models.md` for model choice).
