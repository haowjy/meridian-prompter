# Skill Artifacts

Meridian ships its own guide to skills: the folder shape, how a skill reaches an agent,
invocability, and types. Read it with `meridian skills prompt-authoring__meridian`, then
its `resources/skills.md`. `/prompt-principles` `resources/skill-level.md` covers how to
design a skill.
